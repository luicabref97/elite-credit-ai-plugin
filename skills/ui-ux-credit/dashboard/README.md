# Audit Report Dashboard

Consumer-facing audit report dashboard for Elite Credit AI.

## Files

- `index.html` — entry point (open directly in a browser)
- `data.js` — sample audit report data + i18n + grade/status color helpers
- `direction-a.jsx` — main dashboard React component
- `pdf-artboard.jsx` — print-friendly PDF view
- `design-canvas.jsx` — pan/zoom canvas wrapper
- `tweaks-panel.jsx` — language / animation toggles
- `styles.css`, `styles-extras.css` — all styling
- `logos/` — Equifax, Experian, TransUnion SVG logos

## Tech

Vanilla React 18 via CDN + Babel standalone (no build step). Open `index.html` in any modern browser.
